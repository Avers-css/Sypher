## 🌟 О проекте

**Sypher** — это суверенная, полностью децентрализованная система защищенного обмена сообщениями, созданная с нуля для полного отказа от центральных серверов, телефонных номеров и облачных баз данных.

Проект объединяет два ключевых преимущества:
1. **Под капотом:** Непробиваемая криптографическая защита по стандартам протокола Signal — **Double Ratchet (X25519 + ChaCha20-Poly1305)**, **эпидемическая маршрутизация сообщений (Gossip DTN)** и **локальная доставка без интернета через прохожих (Bluetooth Low Energy / Wi-Fi UDP Multicast)**.
2. **Снаружи:** Элегантный, аппаратный **интерфейс в стиле Telegram Dark Glassmorphism**, не требующий технических навыков.

## 🛡️ Ключевые возможности

- **0 рублей расходов (Zero Servers):** Работает автономно через локальные ad-hoc сети (`239.255.77.88:7788`), ячеистые сети Bluetooth (BLE Mesh) и Tor.
- **100% Анонимность:** Без номеров телефонов, SIM-карт, SMS, паролей и почт. Идентификатор пользователя — это 256-битный открытый криптографический ключ (`syph1...`).
- **Сквозное шифрование военного уровня:**
  - **Ed25519:** Электронные цифровые подписи.
  - **X25519 (ECDH):** Эфемерное согласование ключей Диффи-Хеллмана.
  - **Double Ratchet:** Постоянное обновление ключей для каждого сообщения (**Perfect Forward Secrecy** и **Post-Compromise Security**). Ключи немедленно стираются из памяти.
  - **ChaCha20-Poly1305:** Симметричный шифр со 128-битной аутентификацией целостности данных.
- **Передача без интернета (Sneakernet / Эстафета через прохожих):** Если получатель не в сети, зашифрованный пакет сохраняется в памяти проходящих мимо телефонов с приложением Sypher и передается при физическом сближении.
- **Экстренное самоуничтожение (Emergency Burn):** Локальная база защищена через PBKDF2 (100 000 итераций) + AES-256-GCM. Кнопка «Burn» моментально затирает ключи и перезаписывает файл базы случайным мусором.

## 📦 Где скачать готовые файлы (.exe, .apk)?

В профессиональных open-source проектах скомпилированные программы не хранятся внутри Git-дерева, чтобы репозиторий не весил сотни мегабайт. Готовые файлы для загрузки публикуются во вкладке **[Releases (Релизы)](https://github.com/Avers-css/Sypher/releases)**:

* **Для Windows:** `Sypher-Setup-1.0.0.exe` (или портативная версия `.exe`)
* **Для Linux:** `Sypher-1.0.0.AppImage` и `.deb`
* **Для macOS:** `Sypher-1.0.0.dmg`
* **Для Android:** `Sypher-1.0.0.apk`

## 🚀 Как запустить из исходного кода

### 1. Требования
* **Node.js**: версия 22.x или 24.x (LTS)
* **npm**: версия 10+

### 2. Клонирование и компиляция ядра
```bash
git clone https://github.com/Avers-css/Sypher.git
cd Sypher
npm install
npm run build
```

### 3. Запуск криптографических тестов
```bash
npm test
```
*Запустит 14 автоматических тестов ядра (генерация ключей, Double Ratchet, симуляция диалога, защита от подделки).*

### 4. Запуск десктопного приложения
```bash
npm run desktop:dev
```

### 5. Консольный клиент (CLI)
```bash
# Генерация нового анонимного ID:
node packages/cli/src/index.js identity

# Запуск фонового узла:
node packages/cli/src/index.js daemon
```
